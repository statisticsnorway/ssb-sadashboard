# Job Vacancies

A time series object with unadjusted quarterly Norwegian job vacancy
rates. Indexes from first quarter 2010 to fourth quarter 2024.

## Usage

``` r
ledige
```

## Format

R time series object with 21 columns and 60 rows. Columns contains
various indexes for Norwegian job vacancy rates in various major
industries (SIC2007). Indices are produced quarterly by Statistics
Norway.

## Source

From Statbank Norway. (April 11, 2025),
https://www.ssb.no/en/statbank/table/08771/
